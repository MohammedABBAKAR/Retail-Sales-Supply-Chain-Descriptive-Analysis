# Retail Sales & Supply Chain Descriptive Analysis

## Overview
This project is a descriptive analytics dashboard built in Power BI to analyze retail sales and supply chain performance.  
It provides insights into sales, profit, discounts, returns, customer behavior, and retention over time.

The project was created as part of my data analytics portfolio, with a focus on combining business-oriented analysis, interactive reporting, and clear data storytelling.

## Objectives
This project aims to answer key business questions such as:

- What are the total sales, profit, number of orders, and customers?
- How does performance evolve over time?
- Which categories and products contribute the most to sales and profit?
- How do discounts impact profitability?
- Which categories or products generate losses?
- What is the return rate, and where is it concentrated?
- Who are the most valuable customers?
- How does customer retention behave over time through cohort analysis?

## Key Insights
Some of the main findings from the analysis:
- higher discount bands are associated with lower profitability
- some categories generate strong sales but weak margins
- certain products or categories contribute to losses despite having sales
- returns are more concentrated in specific categories or regions
- cohort analysis shows a gradual decline in customer retention after the first purchase month
